# Feet

**Feet are optional.** Without them the shell sits directly on its base, and the four foot bosses in the shell stay empty. If you want feet, pick **solid** or **adjustable**. Both live under `stls/feet/v1/`.

| Variant | STL | Use when |
| --- | --- | --- |
| Solid | [`Feet-Solid.stl`](../../stls/feet/v1/Feet-Solid.stl) | Flat desk, simplest print |
| Adjustable | [`Feet-Adjustable.stl`](../../stls/feet/v1/Feet-Adjustable.stl) | Need to level or change viewing angle |

## Hardware

See [Required hardware](../hardware.md). Adjustable-feet inserts go in the **shell**.

| Variant | Inserts |
| --- | --- |
| Solid | None (and no M3 inserts in the shell for feet) |
| Adjustable | 4× M3 insert in the shell; feet screw into those |
